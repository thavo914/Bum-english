# 🎮 Bum English Hub (CEFR A1–A2)

Welcome to **Bum's English Learning Repository**!  
Designed especially for **Bum (14 years old)** to build solid foundational English through fun, relatable themes (gaming, tech, football, friends, school life, and snacks).

---

## 🗓️ 2-Week Starter Curriculum

| Week | Theme | Target Grammar | Daily Folders |
| :--- | :--- | :--- | :--- |
| **Week 1** | **Myself, Tech & Gaming** | Verb *To Be*, *Have got*, *Can/Can't*, *Present Simple* | `day-01` to `day-05` |
| **Week 2** | **School Life, Friends & Fun** | *Pronouns*, *Like/Love + V-ing*, *Some/Any*, *Present Continuous* | `day-01` to `day-05` |

---

## 📂 Repository Layout (Strict 2-File Daily System)

Each day is contained in its own clean folder with **exactly two files**:
```
lessons/
├── week-01-myself-tech-gaming/
│   ├── week-overview.md
│   ├── day-01/
│   │   ├── 01-knowledge.md      # 5 words + IPA + 1 grammar rule + mini dialogue
│   │   └── 02-exercises.md      # Puzzles + translation + AI Voice prompt + answers
│   ├── day-02/
│   ├── day-03/
│   ├── day-04/
│   └── day-05/
└── week-02-school-life-friends/
    ├── week-overview.md
    ├── day-01/
    ├── day-02/
    ├── day-03/
    ├── day-04/
    └── day-05/
```

## 🚀 Running the Interactive Web Dashboard & AI Voice Buddy

### Option A: Docker (Recommended)
```bash
docker compose up -d --build
```
Open your browser at: **[http://localhost:3001](http://localhost:3001)**

### Option B: Local Node.js
```bash
npm install
npm run dev
```
Open your browser at: **[http://localhost:3000](http://localhost:3000)**

## 🎙️ Chatting with AI Buddy "Leo"
Every day has an **AI Voice Mission**. Open ChatGPT Voice Mode or the built-in Gemini Live audio bridge and speak directly with Leo:
> *"Hey Leo! I am 14 years old. Today I am learning about my gaming gear. Ask me 3 quick questions in simple English!"*
